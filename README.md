## Spring 기반 주요 기능

### 백엔드 API 및 데이터 관리
- Spring Boot와 MyBatis를 활용하여 학습 콘텐츠, 과제, 성적 관련 REST API 구현
- 데이터베이스 CRUD 연산과 연동, 효율적인 쿼리 작성으로 안정적인 데이터 관리

### 인증 및 권한 관리
- Spring Security + JWT 기반 인증 시스템 구축
- 액터별(Role) 기반 접근 제어 구현
  - **교수:** 강의 및 과제 관리, 성적 확인
  - **교직원:** 사용자 관리, 공지사항 작성, 통계 조회
  - **학생:** 과제 제출, 성적 확인, 강의 참여
- JWT를 HTTP-only 쿠키에 저장하여 XSS 공격 대응
- React(클라이언트)와 JSP(서버사이드) 간 인증 상태 통합 관리

### 실시간 화상 강의 지원
- 초기 WebRTC 기반 Mesh 구조 구현 후 성능 한계 확인
- Zoom API 연동으로 안정적이고 확장 가능한 실시간 강의 기능 제공

### 협업 및 형상 관리
- SVN(Subversion) 기반 코드 형상 관리
- 기능 단위 디렉토리 분리 및 개발/배포 버전 관리
- 주기적 커밋과 충돌 관리로 팀원 간 코드 동기화 유지

### 성과
- 사용자 친화적인 UI와 안정적인 실시간 강의 기능 제공
- JWT 기반 인증으로 SPA ↔ 서버사이드 환경에서 인증 상태 유지
- WebRTC 한계를 경험하고 Zoom API 대체 도입으로 서비스 안정성 확보
